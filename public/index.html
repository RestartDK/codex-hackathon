Access is where we begin

Built around you.Speaking. Listening. Playing.

A game should make room for the player. Playora is being built with blind and low-vision players in mind.

  • Ask about the board

    Explore pieces, squares, and your move history through the companion.

  • Play your way

    Use voice, typed commands, or the keyboard. Adjust narrator volume and move confirmation in settings.

  • Make space for your screen reader

    An optional mode announces text updates and mutes companion audio.

A hackathon prototype, still learning. Testing with blind and low-vision players and across assistive technologies is still ahead.

What is Playora?
Playora

Playora is a hackathon project exploring games through speaking and listening. A conversational companion helps you navigate, understand a game, and make your next move, with blind and low-vision players in mind.

Which games can I try?
Playora

Chess is playable now, against the computer or in local two-player mode. Loups-Garous is also playable, with one human and NPC villagers. Tic-Tac-Toe supports computer and local two-player matches. The collection is intended to grow.

Do I need to see the screen?
Playora

The companion supports spoken navigation, board descriptions, and moves. Starting voice requires an initial action and microphone permission.

Some settings still use on-screen or keyboard controls. Testing with blind and low-vision players and across assistive technologies is still ahead.

How do I start?
Playora

Choose Start playing to open the game picker, then select Chess. To use live voice, select the companion orb and allow microphone access.

You can ask for a quick guide, describe the board, or propose a move. Chess live voice needs a server-side API key; keyboard and typed commands work without that key.

Can I type instead?
Playora

Yes. Open the keyboard button beside the companion orb in the game.

Try “e2 to e4”, “describe the board”, “hint”, or “help”. Say or type “yes” to confirm a proposed move. You can also explore the board with arrow keys and select with Enter or Space.

Can I ask for help with a move?
Playora

Yes. Ask for a hint, a description of the board, or a suggested move.

A suggested move is a proposal and needs confirmation before it is played. You can also ask for a quick guide, review move history, pause, or resume.

Do I need a microphone or API key?
Playora

Chess live voice needs a microphone, your permission, and a server configured with an OpenAI API key. Players do not enter a key on this page. Werewolf can use browser speech recognition and narration without that key, where supported.

Keyboard controls and typed commands work without live voice. This FAQ never asks for microphone access.

What happens to my voice?
Playora

This landing page does not record audio or send your questions anywhere. When you explicitly start live voice in the game, microphone audio is sent to OpenAI for the conversation.

The app saves game position and preferences on your device, but does not store raw audio or transcripts in local storage. Use End voice to close the session. Provider retention is separate from device storage; check the project documentation before enabling voice.
