## Ludo computer-player research

The move priorities in the clean-room TypeScript computer player were informed
by publicly visible behavior in
[`uonliaquat/Ludo_Challenge`](https://github.com/uonliaquat/Ludo_Challenge):
automatic rolling, captures, escaping danger, safe-square moves, exact finishes,
and entering a new token on a six. That repository does not publish a software
license, so none of its C# source code or assets are incorporated here.
